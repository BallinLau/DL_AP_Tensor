# Firm-side checkpoint evaluator

`experiments/evaluate_checkpoints.py` performs a read-only evaluation of one
`PolicyValueModel` checkpoint. It evaluates firm surfaces, physical P0/PI
Bellman residuals, BP teacher consistency/regret, and ETA timing. It does not
evaluate FC1/FC2 training quality, episode drift, or simulated-moment convergence.

## Inputs

- A combined checkpoint with `models.policy_value`, `models.sdf_fc1`, `hyperparams`,
  `config_snapshot`, `policy_value_model_spec`, and `value_parameterization`; or
  a raw policy checkpoint plus explicit JSON sidecars.
- A firm-stage pickle or CSV. Parent medians determine fixed `x`, `Hatcf`,
  `LnKF`, `Hatc`, and `LnK`; each grid fixes the requested current `ETA` and
  scans `b` and `z`. Matrix mode evaluates otherwise identical `ETA=0` and
  `ETA=1` parent grids.
  When `Hatc/LnK` are absent, the evaluator loads the sibling
  `<firm-stem>_macro.pkl` and aligns it by `path/t/branch` or `path/t`.

Strict checkpoint reconstruction is intentional. Legacy checkpoints whose
architecture differs from the current `PolicyValueModel` must be migrated or
evaluated at their source commit; the evaluator never uses `strict=False`.

## Example

```bash
python3 experiments/evaluate_checkpoints.py \
  --checkpoint /path/to/combined_checkpoint.pt \
  --firm-data /path/to/final_stage_firm.pkl \
  --macro-data /path/to/final_stage_macro.pkl \
  --output-dir /path/to/firm_checkpoint_evaluation \
  --device cuda \
  --eta-values 0 1 \
  --n-child-shocks 32 \
  --robustness-child-shocks 2 32 \
  --b-points 101 \
  --z-min -4 \
  --z-max 4 \
  --z-points 101 \
  --i-points 101
```

For raw state dicts, use `--pv-ckpt` and provide `--sdf-ckpt`,
`--hyperparams-json`, `--config-json`, and `--model-spec-json`. Current runtime
defaults are accepted only when the corresponding explicit opt-in flag is passed.

## GPU Slurm

`slurm/run_firm_checkpoint_evaluator_gpu.slurm` runs the same evaluator on one
GPU in the `a01` partition. It defaults to a combined checkpoint, final
simulation firm/macro data, a 101 by 101 `(b,z)` grid, parent ETA values 0 and
1, full figures at J=32, and compact robustness summaries at J=2. `RUN_ROOT`
and `EPISODE` are mandatory.

```bash
RUN_ROOT=/home/fit/zhuyingz/WORK/LiuHao/cachedir/<run> \
EPISODE=9 \
sbatch DL_AP_Tensor/slurm/run_firm_checkpoint_evaluator_gpu.slurm
```

Override the ETA/J matrix when needed:

```bash
RUN_ROOT=/home/fit/zhuyingz/WORK/LiuHao/cachedir/<run> \
EPISODE=9 \
ETA_VALUES="0 1" \
N_CHILD_SHOCKS=32 \
ROBUSTNESS_CHILD_SHOCKS="2 32" \
sbatch DL_AP_Tensor/slurm/run_firm_checkpoint_evaluator_gpu.slurm
```

For an episode-stage reference distribution, explicitly set both files:

```bash
RUN_ROOT=/home/fit/zhuyingz/WORK/LiuHao/cachedir/<run> \
EPISODE=2 \
FIRM_DATA=/home/fit/zhuyingz/WORK/LiuHao/cachedir/<run>/data/outputs/ep2_stage_modeb.pkl \
MACRO_DATA=/home/fit/zhuyingz/WORK/LiuHao/cachedir/<run>/data/outputs/ep2_stage_modeb_macro.pkl \
sbatch DL_AP_Tensor/slurm/run_firm_checkpoint_evaluator_gpu.slurm
```

The script checks that `HEAD` contains the required evaluator commit, rejects
modified tracked files, verifies CUDA, runs the evaluator unit tests, and
validates the output schema and objective-slice counts. Untracked files are
reported but do not block by default; set `STRICT_UNTRACKED_WORKTREE=1` for a
fully clean-worktree requirement. Set `RUN_EVALUATOR_TESTS=0` only after a
tested smoke run. `ALLOW_DIRTY_WORKTREE=1` is reserved for intentional local
diagnostics because it permits modified tracked source files.

## Output semantics

- `default/default_boundary.csv` defines a boundary only when exactly one
  interpolated `Phat=0` crossing exists. Missing and multiple crossings remain
  `NaN`; multiple crossings are excluded from monotonicity and roughness.
- `bar_i_cond` is the conditional investment probability; `bar_i_eff` is the
  survival-adjusted executed probability; `i_star` is the first scanned
  `VI(i)-V0=0` crossing. No gap is computed between these distinct objects.
- `Q` is total debt value. `q_unit=Q/b` only for `b>1e-12`; it is `NaN` at zero.
- BP consistency calls `BPGridTeacher.compute()` directly. Child states and M
  are generated by the checkpoint `sdf_fc1`, `ConvergenceShockBank`, and
  `build_child_exogenous_bundle()` with common random numbers across the frozen
  grid. `n_child_shocks=J` denotes independent continuous shocks. Each shock is
  deterministically expanded into adjacent `eta_next=0/1` states with weights
  `w_j*(1-ZETA)` and `w_j*ZETA`; paired states share `z/i/x/Hatcf/LnKF/M`.
  Therefore the evaluator integrates the Bernoulli refinancing opportunity
  exactly instead of relying on a rare-event draw. Matrix mode generates the
  maximum-J bank first and uses prefixes for smaller J cases. No
  median-transition proxy is used.
- `bellman/` contains physical conditional-mean residuals
  `P0-CF0-E[M_used P_child]` and `PI-CFI-G E[M_used P_child]`, plus value-scale
  normalized diagnostics. These are evaluator outputs, not training losses.
- `audits/child_continuation_audit.csv` records each representative parent,
  candidate BP, and child realization. Its `child_b_identity_error` directly
  checks `b_next=eta_next*bp+(1-eta_next)*b`. `continuation_raw` excludes the
  branch probability, while `continuation_weighted` includes `branch_weight`.
  The older `raw_continuation_term`, `weighted_continuation_contribution`, and
  `continuation_contribution` names remain as compatibility aliases.
- BP consistency includes raw, survival-only, and survival-and-identified
  MAE/regret. Identification uses the teacher objective's top-two margin and
  the configurable `--bp-teacher-margin-tol`.
- `default/boundary_comparison.csv` and `.png` distinguish the hard `Phat=0`
  boundary from the soft `bar_z=0.5` contour.
- Investment diagnostics include `D=VI-V0` at low/mid/high investment costs,
  sign regions, monotonicity violations, and crossing-status shares. The legacy
  monotonicity headline remains raw; the preferred economic headline is
  `investment_i_monotonicity_violation_share_survival`.
- `--macro-data` has priority when supplied. Without it, the evaluator tries
  `<firm-stem>_macro.pkl` and then `*_firm.pkl -> *_macro.pkl`, covering both
  stage outputs and `final_simulate_firm.pkl -> final_simulate_macro.pkl`.
- BP outputs include explicit `_raw`, `_survival`, and
  `_survival_identified` surfaces. Primary BP statistics require both `Phat>0`
  and an identified teacher objective; raw and survival-only diagnostics remain.
- `investment/investment_boundary.csv` classifies `all_invest`,
  `all_no_invest`, `single_crossing`, `multiple_crossings`, `nonfinite`, and
  records the survival region separately. `i_star` is defined only for a single
  crossing in survival.
- BP teacher metadata is explicitly `policy_value`: the diagnostic compares the
  policy with the current online value surface, not with a saved `firm_target`.
  Matrix mode first generates the maximum-J shock bank and takes prefixes, so
  `J=2` is a strict subset of `J=32`. The default formal figures use J=32;
  J=2 remains the training-like robustness comparison.
- `metadata.json` records the grid, reference state, transition bank, checkpoint
  metadata, and before/after parameter hashes.

## Training expectation semantics

The formal training baseline sets `pv_exact_eta_integration_enabled=True`,
`pv_eta_resample_enabled=False`, and `eta_active_reweight_enabled=False`.
P0, PI, Q, BP-grid, and cached P/PI targets evaluate both future eta states for
each continuous child. P0/PI/Q and FOC residuals are then collapsed within each
eta pair before AiO, so AiO still receives exactly `J` independent continuous
shock residuals, never `2J` dependent eta-expanded residuals. The old sampled
eta path and rare-event compensation settings remain available only as explicit
ablation configuration.
