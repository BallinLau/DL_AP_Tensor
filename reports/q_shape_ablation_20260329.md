# Q 形状先验关闭说明

## 背景

当前 `Q(bp)` 训练中使用了一组固定区间的形状先验：

- `b <= 0.2` 时鼓励 `dQ/db > 0`
- `b >= 0.8` 时鼓励 `dQ/db < 0`
- 同时要求 `dQ/dz > 0`

这等于默认了：

```math
Q(b)
```

应该先升后降，且峰值大致位于 `0.2` 与 `0.8` 之间。

## 为什么这次要关闭

这个先验并不是从当前理论模型严格推导出来的，而是经验性的弱单峰约束。当前问题在于：

1. `Q(bp)` 的量级与形状本身已经明显异常；
2. 如果继续保留固定区间形状约束，就无法判断：
   - 是 `Q` 方程和训练本身学出来的结果；
   - 还是 `q_shape` 这个先验把结果推成了某种形状。

我们讨论过将 `q_shape` 改成“基于 default 边界自适应”的版本，但这仍然属于一种先验：

- 只是把峰值位置从固定 `b` 区间，
- 改成与 child default 风险区间挂钩。

用户当前希望先做一个更干净的 ablation：

- **完全去掉 `q_shape`**
- 先看没有任何 `Q` 形状先验时，训练会自然学出什么结果

## 本次修改

在 [hyperparams.py](/Users/ballinliu/Desktop/PHD/Project1/DL_AP_Tensor_conditional_refactor/config/hyperparams.py) 中将：

- `q_shape_weight_z`
- `q_shape_weight_b_low`
- `q_shape_weight_b_high`

全部改为 `0.0`。

这意味着：

```math
L_{shape} = 0
```

`Q` 训练将不再受到任何固定区间单调性约束。

## 预期用途

这次修改的目的不是立刻改善结果，而是回答一个更基础的问题：

> 当前 `Q(bp)` 的异常形状，到底来自方程/训练本身，还是来自人为形状先验？

如果去掉 `q_shape` 后：

- `Q(bp)` 的量级和形状仍然异常，
  说明问题主要在 `Q` 方程、warm-start、训练动态或共享特征；

- `Q(bp)` 形状明显改变，
  说明原来的 `q_shape` 确实在较强地塑造结果。
