# Q 结果仍不理想：第二轮原因分析与改进建议（2026-03-12）

## 1. 结论先行
你现在的 Q 问题，已经不只是“训练不够久/正则不够强”。从参考文档与论文对照看，主要是 **训练对象定义与信息路径** 仍有结构偏差：

1. Q 在预训练阶段仍强依赖未稳定的 policy 分支（`bar_i/bp`），导致“Q-only”并不真正独立。  
2. 缺少论文中的 **结构化 warm-start / pretraining target**（先给 Q 一个经济形状先验）。  
3. 默认机制仍然偏弱（`P` 几乎非负），Q 的违约风险通道信号不足。  
4. `Q` 方程实现中对关键状态（特别是再融资冲击 `eta`）的处理，与论文写法存在简化偏差。  
5. 数据分布（尤其高杠杆区）对 Q 的倒 U 识别仍不够友好。

---

## 2. 与参考论文/文档的关键偏差

### 2.1 论文强调“结构化初始化 + 预训练”，当前实现基本缺失
论文在训练流程中明确给出：先用具有经济意义的函数初始化 `Q/P` 并预训练（`/tmp/dl_equilibrium_extracted_clean.txt:1186-1217`）。

当前代码中 `build_models` 直接随机初始化并进入残差训练：
- `experiments/run_utils.py` 的 `build_models` 与 `build_optimizers` 没有 Q/P 监督预训练步骤。

影响：Q 在早期很容易收敛到“低振幅近零”局部极小值，后续很难靠残差纠正成倒 U。

### 2.2 论文使用分阶段策略，当前虽然加了 Q-only，但仍通过 policy 通道耦合
你已经加了 `q_pretrain_epochs`，但 `_compute_q_loss` 里 Q 仍依赖：
- `bar_i`、`bp`（来自 policy/value 分支）
- 子状态构造中用到 `bp_t`

证据：
- `training/episode.py:786-794, 807-818`

这意味着“Q-only 阶段”并不是真正的“只训练债券定价函数”，仍受未稳定的 policy 子网络干扰。

### 2.3 默认机制信号仍偏弱，Q 的违约分支学习不足
当前默认概率核心通道仍来自 `P`：
- `PHead` 为 `softplus`（非负）→ `models/share_layer.py:147-167`
- `P = clamp(Phat,min=0)`，`bar_z = sigmoid(-50*P)` → `models/policy_value.py:173-176`

这会让 `bar_z` 训练早期常接近 0，Q 方程中的回收分支贡献弱化，Q 更容易塌到“全域偏小”。

### 2.4 Q 方程实现相对论文有简化，可能丢掉关键经济斜率
`q_loss.py` 主残差当前形式：
- `M * ((b + Qsp*multiplier)*(1-bar_z) + recovery*multiplier*bar_z) - Q`
- 证据：`losses/q_loss.py:72-101`

但该实现没有显式出现论文里非常关键的再融资冲击 `eta` 结构项（论文相关描述见提取文本 around page 10 / bond recursion）。

影响：Q 对杠杆与风险状态的敏感性可能被“简化平均化”，形状恢复更慢。

### 2.5 倒 U 识别依赖样本覆盖，当前高杠杆有效样本仍偏弱
你之前的 simulate 分布里高 `b` 覆盖不足（我们第一轮诊断已见）。

即使新增形状正则，如果高杠杆区真实样本少，`dQ/db<0` 那一半边也会学得不稳。

---

## 3. 为什么“这次改了也不理想”

你这次改动（Q-only + AIO + 形状正则 + M-clamp）是正确方向，但主要解决的是“优化稳定性”，还没完全解决“目标定义与信息通道”问题。

换句话说：
- 你让梯度更稳了；
- 但 Q 学到的仍是一个“被简化方程 + 弱违约信号 + 弱高杠杆样本”约束的目标。

所以结果会比之前好一点，但不一定达到论文里的经济曲面质量。

---

## 4. 改进建议（按优先级）

### P0（必须先做）
1. **把 Q 预训练做成真正“解耦”**  
在 `q_pretrain_epochs` 阶段：
- 固定 `bar_i = 0`（或来自外部给定规则），
- 固定 `bp_t = b_parent`（不走 policy 网络输出），
- 只更新 Q 头和 share 层的 Q 路径参数。  
目标：先得到干净的 `Q(b,z)` 形状，再引入 policy 耦合。

2. **加入论文式 Q warm-start 监督**  
按论文给的结构化函数（`Q(b,z,x)` 高斯峰 + 风险项）先做若干 epoch MSE 预训练，再切回残差损失。

3. **Q 阶段样本重采样（高 b 强化）**  
单独对 Q 训练批次做 `b` 分层采样，显式提高 `b>=0.8` 比例。

### P1（高优先）
4. **把 `eta` 再融资冲击显式并入 Q 主残差公式**  
目前 Q 方程相对论文简化，建议按论文递归把 `eta` 路径结构补齐。

5. **Q 形状正则改为分位点自适应区间**  
不要写死 `b_low=0.2, b_high=0.8`，改成按 batch 分位点（如 25/75 分位）动态确定，避免不同数据集下正则“打空”。

### P2（中优先）
6. **恢复默认通道的可学习性（间接改善 Q）**  
如果 `bar_z` 一直太小，Q 的回收分支永远学不出来。建议逐步放松 `P` 的硬正值偏置，或引入独立 `bar_z` 监督项。

## 5. 可操作实验设计（建议）

做 3 组 A/B，快速定位瓶颈：

1. `A`: 当前版本；`B`: Q-only 完全解耦（固定 `bar_i,bp`）  
看 Q 倒 U 与 z 单调是否明显改善。

2. `A`: 无 warm-start；`B`: 先监督预训练 Q（20-50 epoch）再残差训练  
看 Q 是否仍塌到近零。

3. `A`: 原采样；`B`: Q 批次高 b 重采样  
看高杠杆区域斜率是否变负、边界是否更合理。

---

## 6. 你现在最该做的一件事
如果只能做一件事：
**先把 Q-only 阶段从“损失解耦”升级到“路径解耦”（固定 `bar_i/bp`），再配 warm-start。**

这一步对 Q 形状恢复通常最直接，且不需要你立刻重构全部 P/default 模块。
