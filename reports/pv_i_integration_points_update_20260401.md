# `P / Vhat / chi / bar_z` 的 `i` 离散积分点数更新（2026-04-01）

## 背景

当前 `P / Vhat / chi / bar_z` 不是基于单个 `i` 计算，而是对一组离散的 `i` 点近似积分：

```python
Vhat = mean_i max(V0(i), VI(i))
```

此前默认使用 5 个等距点：

- `0.00`
- `0.05`
- `0.10`
- `0.15`
- `0.20`

在 `I_THRESHOLD = 0.2` 的设置下，这个分辨率偏粗。若 `VI - V0` 的切换边界对 `i` 较敏感，5 点平均会把边界抹得过于粗糙，影响：

- `Vhat`
- `P`
- `chi`
- `bar_z`

## 修改

将默认离散积分点数从 5 提高到 11，并做成显式配置项：

- `Config.PV_I_INTEGRATION_POINTS = 11`

对应默认网格变为：

- `0.00`
- `0.02`
- `0.04`
- `0.06`
- `0.08`
- `0.10`
- `0.12`
- `0.14`
- `0.16`
- `0.18`
- `0.20`

## 预期影响

1. `Vhat = E_i[max(V0, VI)]` 的近似更平滑、更稳定。
2. `P / chi / bar_z` 对投资成本分布的响应不再过度依赖粗网格误差。
3. 在 `VI - V0` 对 `i` 边界敏感时，投资区与违约区的切换会更自然。

## 成本

`cal_phats(...)` 内部需要对每个 `i` 点重算一次 `V0 / VI`，因此计算量会增加。  
从 5 点到 11 点，大约增加到原先的 2.2 倍。当前优先级是提高经济对象的一致性与稳定性，这个代价是可接受的。
